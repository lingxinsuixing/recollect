02 / memory model

Memory is an index,
not a transcript

A memory answers only what the conclusion is, who it is about, when, and where it came from. The original text never enters memory; it stays in the raw transcript table. By turn number, use recollect_turn to fetch that turn, with up to 10 turns of context on either side. So the model can be swapped at any time and prompts can be edited at any time, while not a single byte of the original session is lost.

01

Two halves: its own, and the world's

Memory is not one thing. One half is the agent's own encrypted notebook, visible and writable only to itself; the other half is the world it lives through with you, searchable, traceable, and readable by other agents under the same person. World memory is shared across devices and agents: everyone extracts and recalls together; core accepts only a single agent's key.

self · encrypted notebook

core

One per agent, stored encrypted. Persona, its understanding of its owner, mood, unfinished business, passing notes: all of it is its own stance, written by itself, never produced by automatic extraction and never shared with others.

Two kinds of agent, two sets of needs

The tools are the same; the focus differs. Companion agents lean on the always-on brief, mood, and profile; engineering agents lean on the timeline, handoffs, and original words. Each uses the other's: companion agents also read world memory, and engineering agents have their own core.

04

What actually gets remembered

Not a copy of the chat log, but six kinds of thing you can use directly; each one traces back to the original words.

01 / fact
Fact

Who, where, what, how many. Can be cited repeatedly, and can be overturned.

The deploy script is scripts/build-release.sh

02 / event
Event

When it happened, what happened, how it turned out. Timestamped, so it lines up.

The release process changed once on Oct 24

03 / decision
Decision

What was decided, why, and whether it changed later. The old row is marked "superseded", not deleted.

Branch first, then merge; never push to main directly

04 / state
State and mood

How it felt and where things stood at the time, with an expiry; it fades out when stale instead of becoming a permanent label.

Wants two days off this week (until Friday)

05 / relation
Relation

Who and whom, what relation, from when. A change adds a new row instead of editing the old one.

A-Lan is a colleague, since Oct 12

06 / anchor
Entity anchor

People, projects, machines, accounts. Every memory hangs on an anchor, so a different wording does not make a different person.

"the recollect project"

Another class is written by the agent itself: persona, user profile, notebook, handoff notes. These live in core, visible only to this agent; the six kinds above live in the shared memory layer and can be read, within permissions, by other agents under the same owner.

05

Four ways to read a single recall

A recall first pulls candidates from the local keyword index — exact term matching, no embedding model — then renders the same set of candidates in different ways: for the model, a numbered brief where the line-start [1] is the handle, which trades back into that memory; the turn pointer inside a memory is then resolved with recollect_turn to fetch the original words; for programs, JSON; for whoever is checking, an evidence chain that expands all the way to the original words. Switch tabs to see different cuts of the same memory.

Default view · brief

A recall first renders candidates as one natural-language sentence with [n] handles at the start of each line; the sentence carries context, so it is harder to misread than a pile of fragments and fields. Reading it calls no model, and the model does not have to parse the schema first.

25 formal tables, five directions

The memory layer is not one big table. Identity and provenance, extraction and review, the entities themselves, usage and references, operations: each forms a group, and audit and provenance are built in from the first migration.

No need to memorize table names; the five groups are enough. Each group owns one concern, and a missing group is obvious at a glance.

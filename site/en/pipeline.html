03 / extraction

Thirteen stages,
two kinds of executor

Code handles everything that can be settled mechanically: ordinals, timestamps, who spoke, tool calls, who was mentioned, dedupe, provenance. The model makes semantic judgements only, one at a time, and its output carries only seq and a verbatim quote — no id, no timestamp, no pointer, and no "how sure I am".

Code P1–P17 LLM L1–L12 Code checks + model review
01 / Import
Bring the words in first

The converter writes sessions into one format; unknown fields are rejected and secrets are scanned first.

02 / Distillation
Cut into small batches

One batch per pass, and it can be re-run; a failed batch stops there and the next run resumes from the break.

03 / Extraction
Code locates, model judges

Code supplies ordinals, timestamps and speakers; the model only judges meaning. Whatever code can check is checked first, and model review comes after.

04 / Use
Take out what is needed

Recall gives a one-sentence brief, search gives the raw words, a session gives context; all of them expand the source text by the handle at the start of the line.

No LLM

Searchable once ingested

Every turn is written into the full-text index at import: session lists, raw-word search and replay all return results without calling a model.

With an LLM

Only then does extraction run

Memory cards, review and the always-on brief wait for the model; without it no raw text is lost, and it is filled in when the model comes back.

04

How small can one output be

The model produces only "which turn + which quote + what was extracted". Every other field is assembled by code, so the model has nothing to invent.

llm output contract · v4frozen
// only these fields; no id, timestamp, source position, code, logs or confidence score { "seq": 12, "quote": "Swapped the release script for build-release.sh; the Raspberry Pi side will not come up.", "facts": [ { "subject": "deploy script", "predicate": "single entry point", "value": "build-release.sh" } ] } // no content returns an empty array — no guessing, no padding, no "none" { "seq": 13, "quote": "", "facts": [] }
